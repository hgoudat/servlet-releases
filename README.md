# Servlet

Servlet is a desktop workspace for coding agents, projects, and tasks.

[Download Servlet](https://github.com/hgoudat/servlet-releases/releases) · [Website](https://servlet.ai) · [Report an issue](https://github.com/hgoudat/servlet-releases/issues)

## Downloads

Open [Releases](https://github.com/hgoudat/servlet-releases/releases) to find available versions, release notes, and installers. Expand **Assets** to choose the file for your computer.

| Platform | Computer | Installer |
| --- | --- | --- |
| macOS | Apple silicon, macOS 13 or later | `.dmg` |
| Linux | x64 | `.deb` or `.AppImage` |
| Windows | x64 | Coming soon |

Windows downloads will be available when signed installers are ready.

## Install on macOS

1. Download the `.dmg` from a release.
2. Open it and drag **Servlet** into **Applications**.
3. Open Servlet from Applications.

Mac installers are signed and notarized. Use the `.dmg` for installation; the `.zip` is used for app updates.

## Install on Linux

For Ubuntu or Debian, download the `.deb` and install it with your software installer. You can also install it from a terminal:

```sh
sudo apt install ./Servlet-<version>-linux-x64.deb
```

Replace `<version>` with the version you downloaded.

For the AppImage, download the `.AppImage`, allow it to run as a program in the file's permissions, then open it.

## Updates

On macOS, Servlet shows an in-app notice when an update is available. Open **Settings → Application updates** to review and download it. Restart Servlet when you are ready to install the update.

On Linux, download the latest installer from Releases and install it over your current version.

## Help

For bugs or installation help, [open an issue](https://github.com/hgoudat/servlet-releases/issues/new). Include your operating system, Servlet version, and the steps needed to reproduce the problem.
